# Modern Production Research (MPR) Community Code of Conduct

## 1. Engineering Pledge

We aim to make participation in the MPR open-source community professional, respectful, and productive.

## 2. Professional Standards

Contributors are expected to follow these principles:

- **Data-Driven Discourse:** Technical claims should be supported by benchmarks, logs, telemetry, or reproducible evidence where appropriate.
- **System-First Intent:** Engineering decisions should consider scalability, latency stability, reliability, and resource protection.
- **Collaboration:** Technical disagreements should focus on implementation, algorithms, architecture, and engineering tradeoffs.

Prohibited behavior includes trolling, personal attacks, harassment, and deliberate disruption of project discussions or triage.

## 3. Enforcement

Project maintainers may moderate discussions, request changes, close contributions, or restrict participation when community standards are violated.

Security vulnerabilities should be reported according to `SECURITY.md` rather than disclosed publicly.
